# Internationalization

Manual i18n — no i18n library. Strings go through `t()` over `src/i18n/translations.ts`.

- Every user-facing string goes through `t()`; never hardcode UI text in components.
- New strings must be added to all supported languages: `es` (default), `en`, `fr` in `src/i18n/translations.ts`.
- Spanish is the default locale.
